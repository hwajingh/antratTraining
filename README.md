# antratTraining — first week

Training exercises. Run the JavaScript files with Node, open the HTML
files in a browser:

```bash
node "first week/aug18-hong.js"
node "first week/weekendAssignment.js"
# open "first week/aug-17-hong/index.html" in a browser
# (links first week/aug-17-hong/stylesheet.css)
```
